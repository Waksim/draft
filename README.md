# TCG Draft Builder

Веб-приложение для проведения драфтов в коллекционной карточной игре Genshin Impact TCG. Сервис позволяет создавать кастомные правила драфта, приглашать двух игроков по уникальным ссылкам и наблюдать за процессом в реальном времени через ссылку для зрителя.

## 🌟 Ключевые возможности

*   **Конструктор драфта:** Создавайте собственные последовательности пиков и банов для персонажей и карт действий.
*   **Сессии в реальном времени:** Используются WebSockets для мгновенного обновления статусов игроков, ходов и истории драфта.
*   **Уникальные роли:** Генерируются отдельные ссылки для Игрока 1, Игрока 2 и Зрителя.
*   **Интернационализация:** Поддержка русского и английского языков.
*   **Адаптивный дизайн:** Пользовательский интерфейс адаптирован для десктопных и мобильных устройств.
*   **Темы оформления:** Присутствует светлая и темная темы.

## 🛠️ Технологический стек

*   **Бэкенд:** Node.js, Express, WebSocket (`ws`), better-sqlite3
*   **Фронтенд:** React, Vite, Styled-Components, react-router-dom, i18next
*   **База данных:** SQLite
*   **DevOps:** Docker, Docker Compose, Nginx, GitLab CI/CD

## 🏗️ Структура проекта

Проект организован как монорепозиторий с использованием `pnpm workspaces`:

*   `draft/`
    *   `backend/`: Node.js приложение (API и WebSocket сервер).
    *   `frontend/`: React SPA (пользовательский интерфейс).
    *   `docker-compose.yml`: Конфигурация для локальной разработки.
    *   `docker-compose.prod.yml`: Конфигурация для production-окружения.
    *   `.gitlab-ci.yml`: Пайплайн для сборки и деплоя.

## 🚀 Локальная разработка

Для запуска проекта на локальной машине вам понадобится **Docker** и **Docker Compose**.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repo-url>
    cd draft
    ```

2.  **Создайте пустой файл базы данных:**
    Поскольку локальная конфигурация монтирует файл БД с хоста, его нужно создать перед первым запуском.
    ```bash
    touch backend/database.sqlite
    ```

3.  **Запустите сервисы с помощью Docker Compose:**
    Эта команда соберет образы (если они еще не собраны) и запустит контейнеры фронтенда и бэкенда.
    ```bash
    docker-compose up --build
    ```

4.  **Готово!** Проект будет доступен по следующим адресам:
    *   **Фронтенд:** `http://localhost:8081`
    *   **Бэкенд API:** `http://localhost:3001`
    *   **WebSocket сервер:** `ws://localhost:3002`
